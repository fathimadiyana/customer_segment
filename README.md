# Customer Segmentation using K-Means Clustering

## Internship
SkillCraft Technology - Machine Learning Task 2

## Objective
To create a K-Means clustering algorithm to group customers of a retail store based on their purchase history.

## Dataset
Mall Customer Segmentation Dataset from Kaggle.

## Features Used
- Annual Income (k$)
- Spending Score (1-100)

## Algorithm Used
K-Means Clustering

## Steps Performed
1. Loaded the dataset
2. Selected important features
3. Scaled the data
4. Used Elbow Method to find optimal clusters
5. Trained K-Means model
6. Assigned cluster labels to customers
7. Visualized customer segments
8. Created Streamlit dashboard

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit
- Google Colab
- VS Code
- GitHub
